# my-iwakuni-cultural-properties-map

岩国市の文化財オープンデータを使って作成した文化財マップです。

## できること

- 文化財を地図上に表示
- 分類ごとの絞り込み
- 文化財名の部分一致検索
- スマートフォン対応

## データ

岩国市が公開している「文化財一覧」のオープンデータを利用しています。

- 出典：山口県オープンデータカタログサイト
- データ提供：岩国市 文化スポーツ振興部 文化財課
- データセット：[岩国市「文化財一覧」](https://yamaguchi-opendata.jp/ckan/dataset/352080-cultural)
- ライセンス：クリエイティブ・コモンズ 表示（CC BY）

文化財の名称、分類、位置情報などをもとに、地図表示用のGeoJSONへ変換して使用しています。
